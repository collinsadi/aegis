## Contracts

### AegisAccount.sol
The agent's smart account. Holds funds, verifies Groth16 ZK proofs on-chain, and supports hybrid ECDSA + PQ operation until the oracle deprecates ECDSA.

**Key functions:**
- `executeWithZKProof(pA, pB, pC, commitment, target, value, data)` — verifies a Groth16 proof and executes an operation
- `executeWithECDSA(sig, messageHash, target, value, data)` — hybrid fallback, works only while `ecdsaActive == true`
- `deprecateECDSA()` — callable only by the registered oracle address

### AegisENSResolver.sol
CCIP-Read resolver (EIP-3668) for `*.0xaegis.eth` subdomains. Stores `pubKeyHash` and `accountAddress` on-chain. Full 1952-byte ML-DSA public keys are served off-chain by the gateway and verified against the on-chain hash.

**Key functions:**
- `registerAgent(node, accountAddress, pubKeyHash)` — register a new agent subdomain
- `rotateKey(node, newPubKeyHash)` — update the on-chain key hash after rotation
- `addr(node)` — resolve ENS name to AegisAccount address
- `text(node, key)` — read an ENS text record
- `setText(node, key, value)` / `setTextBatch(node, keys, values)` — write text records
- `pubKey(node)` — triggers CCIP-Read OffchainLookup revert
- `pubKeyWithProof(result, extraData)` — CCIP-Read callback, verifies hash

### AegisFactory.sol
The single entry point for deploying new AegisAccount contracts. Uses CREATE2 for deterministic addresses — the account address can be predicted before deployment so ENS registration and deployment can be coordinated.

**Key functions:**
- `deployAgent(owner, oracle, pubKeyHash, extraSalt)` — deploys a new AegisAccount and returns its address
- `predictAddressFull(owner, oracle, pubKeyHash, extraSalt)` — predict the account address before deployment
- `isAegisAccount(address)` — returns true if an address was deployed by this factory
- `deployedAccountsCount()` — total number of accounts deployed
- `getDeployedAccounts(from, to)` — paginated list of deployed account addresses

### verifier/Groth16Verifier.sol
Generated by snarkjs from the circuit zkey. Verifies BN254 pairing proofs on-chain. Do not edit this file manually.

## Deploy with Hardhat Ignition

### Local Hardhat node

In one terminal:
```bash
npm run node
```

In another terminal:
```bash
npm run deploy:local
```

This deploys in order:
1. `Groth16Verifier` (no dependencies)
2. `AegisENSResolver` (no dependencies)
3. `AegisFactory` (depends on Groth16Verifier address from step 1)

New agent accounts are then deployed at runtime by calling `AegisFactory.deployAgent()` through the SDK — not through Ignition.

### Sepolia testnet

Create a `.env` file in `contracts/`:
```
SEPOLIA_RPC_URL=https://sepolia.infura.io/v3/YOUR_KEY
DEPLOYER_PRIVATE_KEY=0xYOUR_KEY
```

Then:
```bash
npm run deploy:sepolia
```

### After deployment

Copy the deployed `AegisENSResolver` address and paste it into:
```
config/ens.config.ts → ENS_CONFIG.AEGIS_RESOLVER_ADDRESS
```

Then export ABIs to the SDK:
```bash
npm run export:abis
```

## Ignition modules

| Module | Deploys | Parameters |
|---|---|---|
| `Groth16Verifier.ts` | `Groth16Verifier` | none |
| `AegisENSResolver.ts` | `AegisENSResolver` | `gatewayUrl` |
| `AegisFactory.ts` | `AegisFactory` | none (verifier injected from Groth16VerifierModule) |

Pass parameters at deploy time:
```bash
hardhat ignition deploy ignition/modules/AegisENSResolver.ts   --parameters '{"gatewayUrl":"https://gateway.0xaegis.eth/{sender}/{data}.json"}'
```
